dodoMAKSharmony — мод для Castle Story
======================================

Как поставить:
1. Закрой Castle Story.
2. Запусти CastleStoryModInstaller.exe.
   Если Windows покажет синее окно «Windows защитила ваш компьютер» —
   нажми «Подробнее» → «Выполнить в любом случае» (exe не подписан, это нормально).
3. Установщик сам найдёт игру в Steam. Нажми «Установить».
4. Нажми «Играть» (или запускай через Steam как обычно).

Что делает мод:
- Полный русский перевод, включается сам при каждом запуске.
- Убирает фриз ~11 секунд при создании хоста / подключении к игре.
- Ускоряет загрузку катки (и в одиночке, и по сети).
- Отключает мёртвую аналитику GameAnalytics.
- Встроенный лагометр: F8 — таблица, F9 — записать отчёт
  в папку игры: BepInEx\CastleStoryOptimizer_report.txt

Удаление: запусти установщик → «Удалить мод» → «Да» вернёт игру в исходное состояние.
Файлы самой игры мод не изменяет.

Мультиплеер: ставьте мод ВСЕМ игрокам. Каждый грузит мир на своём ПК, а катка
стартует, только когда загрузится самый медленный. Хост с модом ещё и рассылает
постройки быстрее — темп подстраивается под сеть, чтобы никого не выкинуло.
