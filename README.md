# dodoMAKSharmony — мод для Castle Story

Мод-оптимизатор для **Castle Story** на порте **Castle Story Plus** (Unity 6): меньше фризов, выше FPS, полный русский перевод, меню настроек, где любую функцию можно включить или выключить перед запуском.

Файлы самой игры мод не меняет: всё делается патчами в памяти. Мод работает вместе с [Castle Story Plus](https://github.com/Tricky12321/CastleStoryPlus) — это отдельный мод другого автора, его нужно поставить первым.

## Что нужно

- Windows 10/11
- **Castle Story в Steam** (куплена): https://store.steampowered.com/app/227860/Castle_Story/
- Castle Story Plus (ставится один раз, ссылка ниже)

## Установка (5 шагов)

1. **Поставь Castle Story Plus.**
   Открой https://github.com/Tricky12321/CastleStoryPlus/releases/latest и скачай `CastleStoryPlus-<версия>-windows.zip`.
   Распакуй архив и запусти `install.bat`. Установщик сам найдёт игру в Steam и создаст порт в её папке (`CastleStoryPlus-Unity6`).
2. **Запусти игру один раз через Steam** (кнопка «Играть») и закрой её. Так создаются конфиги.
3. **Скачай наше меню настроек** (внутри уже лежит сам мод):
   https://github.com/dodoMAKSalt/dodoMAKSHarmony/raw/main/release/dodoMAKSharmony-Settings.exe
   Положи файл куда удобно (например, на рабочий стол).
   Windows может показать синее окно «Windows защитила ваш компьютер»: нажми «Подробнее» → «Выполнить в любом случае» (файл не подписан, это нормально).
4. **Запусти `dodoMAKSharmony-Settings.exe`.** Программа сама найдёт игру и предложит установить мод — нажми «Да».
   Если игра лежит не в обычной библиотеке Steam и программа её не нашла, она попросит указать папку, где лежит `Castle Story.exe`. Выбор запоминается, сменить его можно кнопкой «Папка игры…» внизу окна.
5. **Выбери настройки.** Для теста нажми кнопку **«Оптимизация максимум»**, потом **«Сохранить и запустить игру»**. Дальше игру можно запускать и через Steam как обычно — настройки сохранены.

Обновление мода: скачай новый `dodoMAKSharmony-Settings.exe` по той же ссылке и запусти — он предложит обновить мод.

## Меню настроек

Два блока: функции **Castle Story Plus** и функции **нашего мода**, внутри — подгруппы (геймплей, интерфейс, оптимизация…). Отметка = функция включена. Есть поиск по названию и описанию.

| Кнопка | Что делает |
|---|---|
| Как в оригинале | выключает все геймплейные изменения в обоих модах (остаются интерфейс, ускорения, исправления) |
| Включить оптимизацию | включает всё про скорость, остальное не трогает |
| **Оптимизация максимум** | всё для скорости и стабильности, остальное выключает; мультиплеер не трогает |
| Рекомендуемые | значения по умолчанию |
| Включить всё / Выключить всё | как написано |
| Переустановить мод | заново записывает мод в папку плагинов |

Изменения вступают в силу при следующем запуске игры.

## Что даёт мод

- Сборка мусора **кусками** (пауза 160–190 мс раньше → около 60 мс).
- Исправление ошибки Castle Story Plus: бриктроны застывали с песочными часами из-за автоуборки.
- Меньше мусора в частых местах игры, быстрее подсчёт целей добычи, меньше лишней работы с коллайдерами и плашками над головами.
- Русский перевод: меню, обучение, справка, интерфейс Castle Story Plus.
- Приоритеты мастерских (Page Up / Page Down и кнопка «Приоритет» в круговом меню).
- Встроенный замерщик: **Shift+F8** — оверлей, **Shift+F9** — записать отчёт, **Shift+F7** — подробный замер (тяжелее).
- Быстрый выход по Alt+F4.

## Если что-то не так — пришли файлы

После игры в папке `<Steam>\steamapps\common\Castle Story\CastleStoryPlus-Unity6\BepInEx\` лежат отчёты:

- `CastleStoryOptimizer_report.txt` — отчёт раз в минуту и по Shift+F9
- `CastleStoryOptimizer_spikes.txt` — кадры дольше 50 мс
- `CastleStoryOptimizer_timeline.csv` — кадр за кадром по секундам
- `CastleStoryOptimizer_slowlua.txt` — медленные вызовы Lua (если есть)
- `CastleStoryOptimizer_untranslated.txt` — непереведённые строки (если есть)
- `LogOutput.log` — общий лог

Пришли эти файлы разработчику вместе с описанием: что делал и когда случился фриз или вылет.

## Удаление

Удали файл `CastleStoryPlus-Unity6\BepInEx\plugins\CastleStoryOptimizer\CastleStoryOptimizer.dll` — мод выключится, игра останется как была. Castle Story Plus удаляется его собственным способом (см. страницу проекта).

## Мультиплеер

Castle Story Plus требует **одинаковых версий у всех игроков**. Наш мод ставьте всем — это безопасно, но для сети он ничего не меняет.

## Сборка из исходников

```
dotnet build Settings/CastleStoryPlusSettings.csproj -c Release
```
Собирает мод (net35) и меню настроек (net48, WinForms) в корень папки проекта. Нужны .NET SDK и установленная игра с портом (проект ссылается на её библиотеки). Подробности для разработчика — в `CLAUDE.md`.
